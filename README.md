# ⚽ グランドメイキング（少年サッカー・8人制 コート設営現場支援ツール）

小学校の校庭や河川敷など、限られたスペースに合わせて「縦（m）」「横（m）」を入力するだけで、最適な比率での各エリア寸法・メジャーの片道累計目盛り・3:4:5直角出し・歪み防止の対角線を自動計算し、**リアルタイム連動SVGコート図** と **STEP1〜STEP6の具体的な設営手順書** を生成する現場特化型Webツールです。

単一の `index.html` だけで完結しており、外部サーバーやデータベースは不要。GitHub Pagesにアップロードするだけで即座に無料公開できます。

---

## 📱 スマートフォン現場特化機能
- **片手でラクラク操作**: スライダーだけでなく、手袋や雨でも押しやすい `[−]` `[＋]` ボタンや数値の直接テンキー入力に対応。
- **☀️ 屋外・直射日光モード**: 強い太陽光の下でも反射や白飛びで見失わない「白黒極太ハイコントラスト表示」にワンタップ切替。
- **💡 画面スリープ防止（常時ON）**: ペグ打ちやメジャー張り中にスマホ画面が勝手に消えるのを防ぐ Wake Lock 機能を搭載。
- **📋 LINE共有テキストコピー**: 計算されたコート寸法・目盛り表の要約テキストをワンタップでコピーし、コーチ・保護者グループLINEに即座に共有可能。
- **🖨️ A4印刷・PDF保存対応**: ブラウザの「印刷」を押すだけで、コート図・目盛り表・手順書がすっきりまとまったA4シートとして印刷可能。

## 🚀 GitHub Pages での無料Web公開手順（最短3分）

PCまたはスマートフォンのブラウザから、完全無料で即座にWebサイトとして公開できます。

### STEP 1: GitHubリポジトリの新規作成
1. [GitHub](https://github.com/) にログインします（アカウントがない場合は無料登録）。
2. 右上の「**＋**」アイコン → 「**New repository**」をクリック。
3. リポジトリ設定を入力します:
   - **Repository name**: 例 `soccer-pitch-maker` または `ground-make`
   - **Public / Private**: 必ず **「Public」** を選択（無料版GitHub PagesはPublicリポジトリで動作します）。
   - 「Add a README file」のチェックは外したままでOKです。
4. **「Create repository」** ボタンをクリックします。

### STEP 2: ファイルのアップロード
1. 作成されたリポジトリ画面で、**「uploading an existing file」** リンクをクリックします。
2. 本フォルダ内の以下の2つのファイルをドラッグ＆ドロップしてアップロードします:
   - `index.html`
   - `README.md`
3. 画面下部の **「Commit changes」** ボタンをクリックします。

*(※ Gitコマンドをお使いの場合)*
```bash
git init
git add index.html README.md
git commit -m "Initial commit: soccer pitch maker"
git branch -M main
git remote add origin https://github.com/<あなたのユーザー名>/<リポジトリ名>.git
git push -u origin main
```

### STEP 3: GitHub Pages の有効化
1. リポジトリ上部メニューの **「Settings」**（歯車アイコン）をクリック。
2. 左サイドバーの **「Pages」**（「Code and automation」内）をクリック。
3. **「Build and deployment」** の設定:
   - **Source**: `Deploy from a branch`
   - **Branch**: `main` を選択し、フォルダは `/ (root)` のまま **「Save」** をクリック。
4. 1〜2分待つと、画面上部に以下のメッセージが表示されます:
   > **Your site is live at `https://<あなたのユーザー名>.github.io/<リポジトリ名>/`**
5. 表示されたURLをクリックすれば、世界中どこからでもスマートフォンでアクセスできます！

## 📲 スマートフォンのホーム画面に「アプリ（PWA風）」として追加する手順

毎回ブラウザでURLを開く手間を省き、ワンタップで全画面アプリのように起動できます。

### iPhone (iOS / Safari)
1. **Safari** で公開されたGitHub PagesのURLを開きます。
2. 画面下部中央の **「共有」アイコン**（四角から矢印が上に出ているマーク）をタップします。
3. メニューを下にスクロールし、**「ホーム画面に追加」** をタップします。
4. アイコン名（例: `コート設営`）を確認し、右上の **「追加」** をタップします。
5. ホーム画面にサッカーボールのアイコンが追加され、次回からアプリ感覚で起動できます。

### Android (Chrome)
1. **Chrome** で公開されたGitHub PagesのURLを開きます。
2. 画面右上の **メニューアイコン（縦の3点リーダー「︙」）** をタップします。
3. **「ホーム画面に追加」** または **「アプリをインストール」** をタップします。
4. ポップアップで **「追加」** をタップします。

## 📐 主要機能 & 計算仕様

### 1. プリセット & 自由設定
- **U-8 ミニ**: `50m × 32m` (少年フットサル/ミニサッカー)
- **U-10 標準**: `60m × 40m` (小学校低学年〜中学年の練習試合・大会)
- **公式 8人制**: `68m × 50m` (JFA日本サッカー協会 8人制公認コート基準)
- **カスタム入力**: 縦 `30〜75m`、横 `20〜55m`、ゴール幅 `3.0m / 4.0m / 5.0m` を自由に設定可能。

### 2. 計算ロジック
- **対角線の長さ**: $\sqrt{\text{縦}^2 + \text{横}^2}$（四角形の歪みゼロ確認用）
- **直角出し（3:4:5 ピタゴラスの定理）**: コートサイズに合わせて扱いやすい最適な組み合わせ（例: `12m - 16m - 20m` や `15m - 20m - 25m`）を自動提示。手持ちのメジャー長さに応じて1倍〜10倍まで自由に変更可能。
- **ペナルティエリア (PA)**: 深さ 縦×0.16 / 横幅 横×0.65
- **ゴールエリア (GA)**: 深さ 4.0m (縦<40mは3.0m) / 横幅 横×0.40
- **PKマーク位置**: ゴールラインから PA深さ×0.75（公式8m、低学年5〜6m）
- **センターサークル**: 半径 横×0.18（5.0m〜7.0m）
- **ペナルティアーク**: PKマークから半径 5.0m〜6.0m

### 3. 現場で一番助かる「ゴールライン片道累計目盛り表」
メジャーの先端（0.0m金具）をコーナーペグに引っ掛け、反対コーナーまで一直線に伸ばしたまま固定し、戻りながら以下の累計目盛りにペグ・印を打つだけで手戻りなくマーキングが完了します:
1. `0.0m`: コーナー（起点）
2. `○○.○m`: ペナルティエリア (PA) 左端
3. `○○.○m`: ゴールエリア (GA) 左端
4. `○○.○m`: ゴールポスト (左)
5. `○○.○m`: ゴール中央（ピッチ中心）
6. `○○.○m`: ゴールポスト (右)
7. `○○.○m`: ゴールエリア (GA) 右端
8. `○○.○m`: ペナルティエリア (PA) 右端
9. `○○.○m`: 反対側コーナー（終点）

※ 「タッチライン目盛り表」や「右から左への測定反転」「各ポイント間の区間差分（＋○m）表示」も完備。

### 4. 動的設営手順書（STEP 1 〜 STEP 6）
入力した寸法がそのまま反映された具体的なステップバイステップ解説:
- **STEP 1【片側タッチラインの基準出し】**: タッチライン全長と中央、直角出し基準点Pのマーキング。
- **STEP 2【3:4:5の定理による直角出し】**: 2本のメジャーを用いた交点Qによる正確な90度の出し方（図解付き）。
- **STEP 3【片側ゴールラインのマーキング】**: 目盛り表に沿ったPA・GA・ゴールポストのペグ打ち。
- **STEP 4【反対側外枠・対角線チェック】**: 対角線による長方形の歪み補正と四隅ペグの確定。
- **STEP 5【センターライン・センターサークル】**: 中央線、センターサークル、四隅コーナーアーク（1.0m）。
- **STEP 6【エリアライン・ペナルティアークの完成】**: PA・GAのボックス結びとPKマーク・アークの完成。
- 各ステップに進捗チェックボックス・プログレスバーを搭載。
